
# Carlos Dev Lab

**Portafolio profesional | Software Engineering | Cybersecurity**

Portafolio web de Carlos Pérez, Analista y Desarrollador de Software, Full Stack, Analista de Datos y Automatizador.

## 1. Visión del proyecto

Carlos Dev Lab busca transformar un portafolio profesional convencional en un laboratorio tecnológico futurista, interactivo y seguro.

La plataforma combinará diseño inmersivo, ingeniería de software, experiencias tridimensionales y mecanismos avanzados de protección.

Su propósito es presentar experiencia profesional, capacidades técnicas, proyectos demostrables y servicios tecnológicos mediante una experiencia digital distintiva.

## 2. Objetivos

- Desarrollar una experiencia web futurista de alto nivel.
- Demostrar competencias reales en desarrollo de software.
- Incorporar animaciones, partículas y escenarios 3D.
- Presentar experiencia, proyectos y servicios profesionales.
- Implementar formularios de contacto funcionales.
- Diseñar una arquitectura de seguridad por capas.
- Construir un sistema privado de monitoreo defensivo.
- Mantener rendimiento, accesibilidad y compatibilidad móvil.

## 3. Experiencia visual

La interfaz se inspirará en laboratorios tecnológicos y sistemas de control futuristas.

Características previstas:

- Escenas tridimensionales interactivas.
- Redes de partículas y efectos de profundidad.
- Paneles holográficos y módulos dinámicos.
- Animaciones vinculadas al desplazamiento.
- Microinteracciones y efectos reactivos.
- Transiciones cinematográficas.
- Adaptación a diferentes dispositivos.
- Compatibilidad con preferencias de movimiento reducido.

## 5. Security Engineering

La seguridad es un requisito central del proyecto.

Se aplicará una estrategia de defensa en profundidad, basada en estándares reconocidos, mínimo privilegio, reducción de la superficie de ataque y validación continua.

### Controles previstos

- Protección de secretos y credenciales.
- Gestión segura de dependencias.
- Validación estricta de datos de entrada.
- Protección contra ataques web comunes.
- Cabeceras HTTP y políticas CSP.
- Protección contra automatización abusiva.
- Limitación de solicitudes.
- Separación de responsabilidades y permisos.
- Protección del almacenamiento de datos.
- Registro y análisis de eventos de seguridad.
- Pruebas automatizadas y auditorías periódicas.
- Gestión segura de despliegues.

Los controles deberán verificarse antes de presentarlos como implementados.

## 6. Sentinel Security Operations

**Estado: diseño conceptual.**

Sentinel será el sistema defensivo y de observabilidad de Carlos Dev Lab.

### Funcionalidades previstas

- Monitoreo de solicitudes y formularios.
- Detección de comportamientos anómalos.
- Clasificación técnica de eventos de seguridad.
- Registro privado de evidencias relevantes.
- Alertas y respuestas defensivas.
- Métricas del estado de las protecciones.
- Seguimiento de incidentes.
- Panel privado de administración.

Sentinel priorizará la seguridad, la privacidad y la minimización de datos.

El panel administrativo contará con controles de autenticación y autorización independientes de la interfaz pública.

## 8. Desarrollo local

Requisitos:

- Node.js compatible con Vite.
- pnpm.
- Git.

Instalar dependencias:

    pnpm install

Iniciar el entorno de desarrollo:

    pnpm dev

Ejecutar análisis estático:

    pnpm lint

Verificar compilación:

    pnpm build

## 9. Privacidad y confidencialidad

Carlos Dev Lab no publicará código fuente institucional privado, credenciales, datos personales de terceros ni información gubernamental confidencial.

Las experiencias profesionales institucionales se describirán únicamente mediante información pública o autorizada.

Los eventos de seguridad estarán sujetos a controles de acceso, minimización de información y políticas de conservación.
